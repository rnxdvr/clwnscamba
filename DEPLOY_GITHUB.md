# CLWNSCAM — публикация двух версий на GitHub Pages

Этот архив **готов для загрузки в корень репозитория `rnxdvr/clwnscamba`**.

## Что где находится

- `/index.html` — оригинальный CLWNSCAM с новым стартовым выбором версии. Пока человек выбирает, заставка ACCE VIBECODES **не идёт**. Нажав «ОСТАТЬСЯ НА СТАРОЙ», он запускает её с самого начала.
- `/v2.5/index.html` — обновлённый CLWNSCAM v2.5 без дополнительных вопросов (прямой вход).
- `/v2.5/styles.css`, `/v2.5/app.js`, изображения, MP3 — ресурсы новой версии, размещённые рядом с её HTML.
- Изображения и MP3 в корне — ресурсы старой версии.
- `legacy_index.html` — архивный файл из оригинального репозитория, оставлен без изменений.

В **главном `index.html`** новый адрес прописан относительно: `./v2.5/`. Это важно: ссылка работает и в корне домена, и на GitHub Pages внутри `/clwnscamba/`.

## Как выложить через Git (Windows PowerShell)

1. На GitHub: `https://github.com/rnxdvr/clwnscamba` — проверьте основную ветку (**main**).
2. Сделайте резервную копию текущего репозитория (GitHub → Code → Download ZIP) или убедитесь, что всё закоммичено.
3. Клонируйте репозиторий, если ещё нет локальной копии:

   ```powershell
   git clone https://github.com/rnxdvr/clwnscamba.git
   cd clwnscamba
   ```

4. Распакуйте скачанный архив и скопируйте **содержимое** папки `CLWNSCAM_GitHub_Deploy` в папку `clwnscamba` с заменой корневого `index.html`. Папка `v2.5` должна оказаться прямо рядом с `index.html`, а **не** внутри лишней папки архива.
5. Проверьте и опубликуйте:

   ```powershell
   git status
   git add index.html 1.mp3 2.mp3 clwnscam.png acce_vibecodes.png icon-4.png legacy_index.html v2.5 DEPLOY_GITHUB.md README.md
   git commit -m "Add classic/new version chooser and CLWNSCAM v2.5"
   git push origin main
   ```

   Если основная ветка не `main`, подставьте её имя в последней команде.

## Настройка GitHub Pages

- Откройте **Settings → Pages**.
- В **Build and deployment** выберите **Deploy from a branch**.
- Ветку выберите `main`, папку — **/(root)**, нажмите Save.
- Дождитесь публикации, которая отображается в Settings → Pages / Actions.

При стандартном URL проекта:

- **Старая версия + окно выбора:** `https://rnxdvr.github.io/clwnscamba/`
- **Новая версия напрямую:** `https://rnxdvr.github.io/clwnscamba/v2.5/`

Если проект опубликован на **своём домене**, основной адрес будет иным, но путь к новой версии останется `/v2.5/` относительно корня проекта.

## Важно

- Выбор появляется **при каждом новом открытии старой версии**. Он не записывается в localStorage.
- Старый функционал и его стартовая анимация сохранены. Изменена лишь отсрочка старта заставки до выбора.
- Для надёжной публикации загружайте всю папку `v2.5/` **с ресурсами** — одного HTML-файла недостаточно.
- Если не видно изменений сразу после публикации, сделайте обновление страницы без кеша (Ctrl+F5).
- Эмоут 7TV на новой версии загружается из внешнего CDN.
